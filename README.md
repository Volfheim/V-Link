# V-Link ⚡

**V-Link** — быстрое и удобное приложение для передачи файлов между устройствами в одной локальной сети.

## ✨ Возможности

- 🚀 **Высокая скорость**: асинхронная передача и адаптивные параметры потока.
- 🔒 **Безопасный режим (опционально)**: шифрование, проверка целостности и аутентификация.
- 🔎 **Умное обнаружение устройств**: mDNS/Zeroconf + fallback по альтернативным IP.
- 🧭 **Режим нестандартных сетей**: совместимый стек для сетей с ограниченным multicast/mDNS (вузовские и гостевые Wi-Fi, мобильные хотспоты).
- 🌉 **Relay-режим (опционально)**: передача через relay-сервер для сетей с client isolation, где прямой P2P запрещён.
- 🌐 **Стабильность в сложной сети**: работа в сценариях с VPN и несколькими интерфейсами.
- 🔋 **Low-power режим**: минимальная нагрузка в фоне.
- 🪟 **Удобство Windows**: трей-режим, автозапуск, drag-and-drop.

```bash
git clone https://github.com/Volfheim/V-Link.git
cd V-Link
pip install -r requirements.txt
python src/main.py
```

## 🏗 Сборка

```bash
python build.py
```

Готовый `.exe` будет в папке `dist/`.

## 🌉 Relay Режим (для кампусных и гостевых сетей)

Когда в сети запрещены прямые соединения между клиентами, включите Relay в настройках:

1. В `Настройки -> Сеть` включите `Relay-режим`.
2. Укажите `Relay URL` (например `http://YOUR-SERVER:8090`).
3. Укажите одинаковый `Канал` на обоих устройствах.

### Reference relay server

В проекте есть reference-реализация relay-сервера:

```bash
python relay/relay_server.py
```

По умолчанию сервер слушает `0.0.0.0:8090`.
