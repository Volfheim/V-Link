# Project Instructions

## GitHub Releases

- Use a lowercase `v` followed by the version number as the release title, for example `v2.4.4`.
- Write release notes in English and match the concise heading-and-bullet style of existing releases.
- Include only user-visible changes. Do not add test results, verification details, installation steps, hashes, or internal release process notes unless explicitly requested.
- V-Link updates are delivered through the in-app updater, so release notes do not need manual installation instructions.
